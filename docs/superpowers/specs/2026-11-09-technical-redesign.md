# Technical product redesign

Latest user feedback supersedes the guided tutorial and miniature 3D scene in the migration design. Keep React/Node, SEO, API, Vercel setup, actual product videos and the explicitly requested 90% slogan.

Direction selected by user: Vercel-inspired restraint in the existing blue/navy palette. Wide architectural line drawing behind the hero, generous type and thin continuous rules. No decorative status dots, check badges or numbered workflow tiles. Replace Manrope with visibly different IBM Plex Sans (self-hosted Cyrillic and Latin). Remove the simplified React tutorial and all links/FAQ claims about it. Retain functional video selection and accessible mobile navigation.

Approach: an original vector technical drawing based on the application's verified built-in 12 × 9 m house geometry. It scales across the entire hero background and is clearly described as the built-in example's contour, rather than presenting another manufacturer's drawings as this product's output. Actual recordings demonstrate the application's real interface. Third-party Doka/PERI drawings inform technical visual conventions, and Vercel informs spacing/hierarchy, without copying proprietary assets or branding.

Rewrite copy around drawing geometry, panel layout, bills of materials, changes of height, PVC cutting, PDF, project files. Verify feature claims against app sources. Ask the owner about target audience and commercial terms; don't invent prices, licensing rules or support commitments. Apply shared typography/alignment across all pages. Validate build, SSR, form failures, video selection, FAQ, direct routes/404 and responsive pages in browser before commit/push.

Additional user requirements: diagnose C# Output/Projects errors in IDE; verify
site itself has no .NET dependencies. Observed VS Code C# extension invoking
`dotnet --info`; documented workspace-only disable instructions without changing
global extensions. Fix full-screen logo on page entry: render-blocking CSS in
HTML head and intrinsic SVG dimensions, tested with JavaScript withheld. Native
cross-document transitions and smooth anchor scroll with reduced-motion support.
