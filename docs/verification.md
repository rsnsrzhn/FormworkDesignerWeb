# Проверка сайта после переработки

Дата: 2026-11-09. Каталог: `~/Projects/FormworkDesignerWeb`.

## Выполнено

- TypeScript, production-сборка, форматирование и `git diff --check`.
- 13 проверок: серверные запросы/валидация, реальный обработчик доставки с
  контролируемыми ответами провайдера, rate limit, клиентский контракт успеха,
  SSR страниц, copyright и первый HTML-кадр. Удалены четыре проверки удалённого
  учебного редактора; добавлена проверка раннего CSS и размеров логотипа.
- Production Chromium: шесть страниц на 360, 390, 768, 1024 и 1440 px без
  горизонтального скролла. Новые шрифты, выбор видеороликов, мобильное меню,
  геометрия полей, снятое начальное согласие, ошибки формы с сохранением ввода,
  имитированный успех, FAQ и настоящий HTTP 404. Ошибок гидратации/выполнения нет.
- Первый production-кадр проверен с полностью выключенным JavaScript: стили
  применены, логотип ограничен размером 32 × 32.
- Dev-сервер на 5173 проверен отдельно с намеренно задержанным `src/main.tsx`:
  CSS и IBM Plex Sans объявлены до запуска клиентского JS, логотип не растягивается.
- При обычной настройке движения Chromium подтверждает `scroll-behavior: smooth`,
  поддержку View Transitions и наличие соответствующего CSS. Основной браузерный
  прогон использует reduced motion; его настройка отключает переходы и скролл-анимацию.
- Просмотрены desktop/mobile скриншоты главной и формы; обновлён social preview
  1200 × 630. Снимки проверок в игнорируемом `test-results/`.
- Независимый reviewer не нашёл Critical/Important проблем. Найдено и исправлено
  незакрывающееся мобильное меню после ссылки-якоря: воспроизведено в Chromium,
  добавлена регрессионная проверка закрытия при выборе «Приложение».

## Содержание и локальная IDE

Возможности повторно сверены с исходниками приложения. Исправлено утверждение
об отдельном экспорте SVG: актуальная пользовательская выгрузка — PDF и HTML.
Вопросы о коммерческой модели и составе поддержки заданы владельцу, до ответа
не публикуются вымышленные условия. Лозунг про 90% сохранён по прямой просьбе
владельца с пояснением о предварительной оценке.

Файлов C#, .NET-проектов и вызовов dotnet в актуальном дереве сайта нет.
Найденное сообщение Output «The .NET SDK cannot be located» поступает из
`ms-dotnettools.csharp` в VS Code, а не из npm-сборки. Глобальные расширения
пользователя не менялись; в README описано отключение для рабочей области.
