# Проверки среды разработки

Дата: 2026-11-03.

## Выполнено

- TypeScript: строгая проверка типов и production-сборка React/Webpack.
- Клиентская валидация и серверный рендер всех типов страниц.
- 21 проверка C#-валидации и настроек production-приёма без внешних NuGet-зависимостей.
- Проверка синтаксиса Docker Compose (`docker compose config --quiet`).
- Проверка сценария зависшего восстановления: запуск с тестовым процессом NuGet останавливается по заданному таймауту с ненулевым кодом и понятным сообщением. Это проверка управления процессами, не восстановления реального пакета.
- Отдельная компиляция API и фоновой задачи против ASP.NET Core с временной заглушкой интерфейса хранилища: без ошибок. Это не заменяет сборку реального SQLite-хранилища или интеграционный тест.
- Подготовка десяти медиафайлов, исключения Git и отсутствие EXE в публичной сборке.

## Ограничения среды

- NuGet недоступен по DNS. `dotnet build FormworkDesignerWeb` остановлен на NU1101 при восстановлении Microsoft.Data.Sqlite; реальный драйвер и API с базой здесь не проверены.
- Открытие локального TCP-порта запрещено (EPERM). Chrome завершается из-за запрещённой операции с сокетом. Браузерные сценарии подготовлены, но не выполнены; скриншоты сайта не получены.
- Docker socket недоступен. Сборку и запуск контейнеров необходимо подтвердить на CI/сервере.
- Windows EXE не запускался: Wine завершается с Bad system call.
- Запись Git заблокирована: `git add` не может создать `.git/index.lock` (Read-only file system). Коммит не создан; исходники остаются в рабочем каталоге.
- Официальные страницы pravo.by и cpd.by ответили 403/503. Подтвердить актуальную на дату запуска редакцию законодательства и завершить документы должен оператор; проект не утверждает юридическую готовность черновика.

Полная проверка: команды в README и `.github/workflows/ci.yml`. Отсутствие доступа не считается успешным прохождением соответствующих тестов.

## Независимое ревью

Исправлены замечания: HTTPS-origin для имитации браузерного preview, белый список медиа в локальной раздаче и конфликт изменённой заявки при повторном requestId. API возвращает 409 для другого содержимого под тем же идентификатором; редактирование формы создаёт новый идентификатор.

## Обновление дизайна

По замечаниям владельца увеличены размеры текста (не менее 14px в явных CSS-правилах), убраны верхний badge, имитация окон и декоративная точка логотипа. FAQ заменён шестью предметными вопросами. Баннер подготовки политики удалён, сведения об операторе не выдуманы, серверные условия приёма заявок не изменены.

Проверены TypeScript, production-сборка, рендер страниц, клиентская валидация и жизненный цикл scroll reveal: reduced motion, однократное появление, отключение и очистка наблюдателя. CSS разобран парсером; проверено отсутствие явных размеров текста менее 14px. Независимое ревью правок выполнено; сценарий браузерного теста обновлён для нового FAQ, размеров текста и анимаций. Реальная визуальная проверка остаётся невыполненной из-за ограничения запуска браузера.

## Бело-синий редизайн

После освобождения диска реализована новая композиция главной и полностью заменена система CSS. Android и десктоп добавлены на главную, страницу покупки, в FAQ и футер. Пять реальных демонстраций сохранены; производительность и равенство возможностей версий не выдумывались.

Снова проходят строгая проверка TypeScript, production-сборка, клиентские тесты валидации/анимаций и рендер страниц. Парсер CSS не обнаружил синтаксических ошибок; явные размеры текста не менее 14px. Независимое статическое ревью существенных дефектов не обнаружило.

Браузерный тест дополнен матрицей шести страниц на ширинах 360/768/1024/1440px. Его исполнение повторно заблокировано ограничением сокетов при запуске Chrome и headless shell. Матрица подготовлена, но не считается пройденной; визуальные результаты и скриншоты не подтверждены.

## Переходы страниц и favicon

После сообщения владельца о задержках View Transitions, снимки main и flushSync удалены. Маршрут обновляется обычным setPath. После DOM commit применяется только opacity заголовка от 0.65 до 1 за 160 мс; main и видео не анимируются целиком. Нет новых библиотек, задерживающих навигацию callback или дополнительных запросов API. Проверены reduced motion, фоновые вкладки, очистка, отсутствие snapshot API и безопасный отказ Web Animations. Сброс прокрутки и фокус выполняются до отрисовки новой страницы. CSS-анимации первоначального hero также удалены, чтобы не накладываться на смену страницы.

Для синего логотипа добавлены новые URL SVG/ICO и fallback /favicon.ico. ICO содержит размеры 16/32/48/64; структура файла и включение новых ссылок проверены тестом, файлы финальной сборки открыты декодером ICO. Проверены TypeScript, сборка, тесты и синтаксис CSS. Независимое ревью существенных дефектов не обнаружило. Браузерный сценарий дополнен переходом назад и проверкой отсутствия повторного запроса конфигурации, но реальное исполнение по-прежнему ограничено средой.
