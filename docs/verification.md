# Проверка миграции React / Node.js

Дата: 2026-11-09. Рабочий каталог: `~/Projects/FormworkDesignerWeb`.

## Подтверждено локально

- `npm test`: 16 проверок модели, запросов, доставки, rate limit, рендера и клиента.
- `npm run build`: проверка TypeScript и production-сборка; шесть HTML-страниц
  и отдельная `404.html`. JavaScript клиента — около 267 КБ / 82 КБ gzip.
- `npm run test:browser`: Chromium, реальная production-статика и локальный Node API.
  Все шесть маршрутов на 360, 390, 768, 1024 и 1440 px без горизонтального скролла.
- Урок: ползунки изменяют геометрию, высота учитывается в результате; доступен
  переход назад и сброс. Итоговое окно открывается, закрывается Escape и ведёт
  к форме сотрудничества. Мобильное меню и одинаковая ширина полей проверены.
- Форма: отдельное изначально снятое согласие, клиентская проверка, сохранение
  ввода при недоступной доставке и ошибке API. Ошибочный HTTP 200/HTML не считается
  успешной отправкой. Для успеха нужен HTTP 202 и `accepted: true`.
- Проверки сервера используют настоящий обработчик и контролируемый HTTP-ответ
  почтового провайдера: успех, отказ, неверный ответ и исключение. Письма не отправлялись.
- Независимый read-only reviewer проверил Node HTTP-адаптер на localhost:
  публичная конфигурация 200, тело из потока и из Vercel-подобного parsed body,
  503 без настроенной доставки и 400 для повреждённого JSON.
- FAQ раскрывается, неизвестная страница возвращает настоящий HTTP 404.
- В браузерном прогоне нет ошибок выполнения или гидратации.
- Скриншоты desktop/mobile и формы просмотрены; поля выровнены. Social preview
  сгенерирован размером 1200 × 630 и просмотрен.
- Зависимости проверены npm audit; текущих уязвимостей не обнаружено.
- Проверены форматирование, Git whitespace и исключение локальных/секретных файлов.

## Проверка кода

Независимый reviewer не обнаружил Critical/Important замечаний. Исправлены два
Minor: слишком широкое принятие HTTP 2xx клиентом и недетерминированный год
в футере, способный вызвать несовпадение гидратации после Нового года.
Добавлены проверки обоих случаев.

## Не подтверждено внешним запуском

- Live deployment на Vercel, его маршрутизация и упаковка функций: аккаунт
  и проект Vercel в этой работе не подключались.
- Реальная доставка через Resend: нужны аккаунт, разрешённый отправитель,
  получатель и серверный ключ владельца. Ключ не хранится в репозитории.
- DNS/HTTPS собственного домена и доступность из сетей конечных пользователей.
- Запуск Flutter-приложения: SDK не найден. Возможности сайта подтверждены
  чтением исходников, а не функциональным прогоном Flutter.
- Юридическая достаточность опубликованных сведений; владелец заполняет контакты
  и условия фактической обработки перед включением настоящих заявок.
