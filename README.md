# FormworkDesigner

Сайт приложения для расчёта опалубки и построения чертежей. На сайте представлены записи работы программы и форма заявки.

Стек: React, TypeScript, Vite. Требуются Node.js 24 и npm.

## Запуск

```bash
npm ci
npm run dev
```

Откройте http://localhost:5173. Остановка — Ctrl+C.

Локальные настройки задаются в `.env` по образцу `.env.example`. Файл `.env` не добавляется в Git.

## Сборка и просмотр

```bash
npm run build
npm run preview
```

Откройте http://localhost:4173.
